    01 · Getting started

    Build X from source

    Only invited collaborators can clone the repository while it remains private. You need Git and a Rust toolchain compatible with the workspace; its current manifest declares Rust 1.82. No public binary or official package installer has been verified.

    Prerequisite: authenticated access to Rocky5502/X. These are instructions, not a claim that your operating system has passed a current release test.
    Terminal · repository checkout
    git clone https://github.com/Rocky5502/X.git
cd X
cargo run -p xc -- check examples/hello.x
cargo run -p xc -- run examples/hello.x

    Expected reference example

    The documented examples/hello.x returns 42. This is a reference interpreter, not compiled native execution.

    Working with the Rust workspace

    Quality checks
    cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace

    Current GitHub Actions release jobs have failed before receiving runners. The commands above are a reproducibility recipe; passing CI on the current draft branches has not been established.

    02 · Language reference

    A small compositional core.

    Typed functions and control flow sit alongside evolving ownership and effect checking. The implementation is intentionally incomplete.

    Bootstrap subset

    Functions and values

    Typed parameters and returns; primitive scalars; let, var, assignment, calls and branching.

    Bootstrap subset

    Ownership and references

    Affine move checks, shared/mutable borrowing, dereference and certain non-lexical borrow patterns.

    Bootstrap subset

    Structs, enums, generics

    Struct construction/field access, selected payload enums with match, and generic function inference.

    Designed for later

    Backends, AI and GPU

    Full HIR-to-IR lowering, LLVM, tensor runtimes, language server and mobile packages remain unshipped.

    Readable stages.
    Testable boundaries.

    X uses a Rust-based lexer, parser, HIR, semantic checker and reference interpreter. A separate typed Core IR implementation has its own verifier.
