Meet XCook.
Evidence before automation.

XCook provides seven experimental development skills and opt-in Python/C++ syntax checking. Separate Core IR drafts now investigate affine ownership and reference provenance; those Rust tests remain unexecuted. MIT licensing applies only to XCook; the X compiler remains Apache-2.0.

Developer-scale quality · Research direction

Built for usefulness.
Not inflated promises.

Reaching a million developers would require proven installation, consistent semantics, editor support, secure distribution and real community trust. That is an aspiration, not a forecast or claimed user count.

01

First-run reliability

Our private XCook draft adds a no-execution doctor checklist. Public installers and verified cross-platform binaries remain future gates.

Read the onboarding design ↗
02

Independently correct code

Prioritize reproducible Rust compiler tests, helpful diagnostics, an explicit language specification and hidden semantic oracles before performance claims.

Track the current evidence ↗
03

Human and AI trust

Keep developer authority and tool permissions explicit. Test actual assistants, source provenance and reliable workflows instead of equating a prompt with a verified result.
