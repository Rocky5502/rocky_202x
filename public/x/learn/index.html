Lesson 01

Make a program return 42

In X's implemented bootstrap syntax, functions use fn, typed parameters and an explicit return type. The program below matches the documented reference example.

examples/hello.x
fn add(a: i32, b: i32) -> i32 {
    return a + b;
}

fn main() -> i32 {
    return add(20, 22);
}

Here, add combines two 32-bit integer parameters. main calls it and returns the result.

Lesson 02

Check, then execute

From an authorized checkout of the private repository, run the following:

Terminal
cargo run -p xc -- check examples/hello.x
cargo run -p xc -- run examples/hello.x

According to the documented reference example, successful execution yields 42. Your toolchain and operating system need their own actual validation.

This educational page does not run X in your browser. The JavaScript teaching playground remains a separate, unmerged project review and is not equivalent to Rust xc.
Lesson 03

Change a value. Make a prediction.

Try changing add(20, 22) to add(21, 22) in your local copy, then rerun the reference toolchain. Predict the new result before execution. This is an exercise to perform yourself, not an automatically verified example.
