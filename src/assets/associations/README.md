# Association artwork

These small image assets are checked into the site to avoid remote favicon service failures.

- `iaseai.png`: site favicon downloaded from the International Association for Safe & Ethical AI's official `https://www.iaseai.org/favicon.png`, October 16, 2026. Used to identify the professional association; not a claim of endorsement.
- `acm.svg`: ACM identifier from the [theSVG ACM icon](https://thesvg.org/icon/acm), provided under CC0-1.0 and using ACM's trademark. Stored locally for stable rendering.

The membership links lead to each organization's official website. Keep any changes consistent with organization brand guidelines; only use the artwork for identification.
